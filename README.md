# 🚗 Carent

Carent is a modern and responsive car rental website built with React and Vite.  
This project focuses on clean UI, smooth animations, and a fast user experience.

## 🌐 Reference Design
Carent Inspiration / Reference:  
https://carent-wbs.webflow.io/

---

## ✨ Features

- Modern Responsive UI
- Smooth Animations using Framer Motion
- Fast Routing with React Router DOM
- Reusable Components
- Mobile Friendly Design
- Clean Folder Structure
- Optimized with Vite

---

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Framer Motion
- React Router DOM
- Lucide React Icons
- React Icons

### Development Tools
- ESLint
- PostCSS
- Autoprefixer

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/malik-tanveet/carent.git

Go to the project folder:

cd carent

Install dependencies:

npm install

Start development server:

npm run dev

Build for production:

npm run build
