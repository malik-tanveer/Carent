# 🚗 Carent

A modern and responsive car rental website built with React and Vite.

Carent focuses on providing a clean user interface, smooth animations, and a fast browsing experience across all devices.

## 🌐 Live Demo

https://carent-wbs.webflow.io/

## ✨ Features

* Modern and Responsive Design
* Smooth Animations with Framer Motion
* Fast Client-Side Routing
* Reusable React Components
* Mobile-Friendly Layout
* Clean Folder Structure
* Optimized Performance with Vite
* SEO-Friendly Structure

## 🛠️ Tech Stack

### Frontend

* React
* Vite
* Tailwind CSS
* Framer Motion
* React Router DOM
* Lucide React
* React Icons

### Development Tools

* ESLint
* PostCSS
* Autoprefixer

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/malik-tanveer/carent.git
```

Navigate to the project folder:

```bash
cd carent
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
